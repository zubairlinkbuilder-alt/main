## Check each GIF against the written steps

The steps were written for the standard version of each movement before the GIFs were bought.
Check these four first, because the title alone doesn't show which variation is animated:

- **Overhead throw (9437):** steps assume a forward, soccer-style throw.
- **Backward throw (8424):** steps assume a squat-and-swing backward overhead toss.
- **Lying leg raise (13026):** steps assume the ball is held between the feet.
- **Dead bug (10176):** steps assume the ball stays above the chest while the legs alternate.

If a GIF shows something different, change the steps to match the GIF.

## Left out on purpose

- *Medicine Ball Throw Squat with Wall* (13861): almost the same as Wall Ball. A second page would compete with it.
- *Medicine Ball Catch and Overhead Throw* (3124): overlaps the overhead throw.
- *Medicine Ball Sit up (wall)*: the title doesn't make the variation clear. Check it before adding.
- *Medicine Ball Lunge with Biceps Curl*: little training value beyond a lunge and a curl done separately.
